# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Run, observe, and verify.

## Practice tasks

**Easy**
1. Start a Node app with PM2 and give it a name.
2. View logs and restart the process.
3. Configure auto-start on system reboot.

**Medium**
4. Run an app in cluster mode across all CPU cores.
5. Write an `ecosystem.config.js` with environment variables.
6. Set up log rotation.
7. Do a zero-downtime reload.

## Interview questions

1. What problems does a process manager solve over running `node` directly?
2. What is cluster mode and why is it useful for Node?
3. How does PM2 keep an app alive after a crash or reboot?
4. What's in an ecosystem file?
5. When would you use PM2 vs letting Docker/Kubernetes manage restarts?
6. How do you achieve zero-downtime reloads?
