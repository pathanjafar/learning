# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, run, and verify.

## Practice tasks

**Easy**
1. Write a Dockerfile for a small Node or Python app.
2. Build an image and run a container, mapping a port.
3. Use a volume to persist data.

**Medium**
4. Write a `docker-compose.yml` for an app + a database.
5. Use a multi-stage build to shrink an image.
6. Set environment variables and a healthcheck.
7. Create a custom network so two services talk by name.

## Interview questions

1. Image vs container — what's the difference?
2. How are containers different from virtual machines?
3. What do volumes do and why do you need them?
4. What is a multi-stage build and why use it?
5. How do containers communicate in Docker Compose?
6. How do you reduce image size?
7. What's the difference between `CMD` and `ENTRYPOINT`?
