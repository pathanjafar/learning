# Production Nginx

## TLS / HTTPS

Terminate SSL at Nginx so your app doesn't have to:
```nginx
server {
  listen 443 ssl;
  http2 on;
  server_name example.com;

  ssl_certificate     /etc/nginx/certs/fullchain.pem;
  ssl_certificate_key /etc/nginx/certs/privkey.pem;
  ssl_protocols       TLSv1.2 TLSv1.3;
}
server {                              # redirect HTTP → HTTPS
  listen 80;
  return 301 https://$host$request_uri;
}
```
**Let's Encrypt** (certbot) issues free, auto-renewing certificates.

## Compression & caching

```nginx
gzip on;
gzip_types text/css application/javascript application/json;

location /static/ {
  expires 30d;                       # browser cache
  add_header Cache-Control "public, immutable";
}
```

## Rate limiting (abuse protection)

```nginx
limit_req_zone $binary_remote_addr zone=api:10m rate=10r/s;
location /api/ {
  limit_req zone=api burst=20 nodelay;
  proxy_pass http://backend;
}
```
This platform rate-limits the code-submission endpoint exactly this way to protect the sandbox.

## Security headers

```nginx
add_header X-Content-Type-Options nosniff;
add_header X-Frame-Options SAMEORIGIN;
add_header Referrer-Policy strict-origin-when-cross-origin;
# add a Content-Security-Policy suited to your app
```

## Performance tuning

- `worker_processes auto;` and tune `worker_connections`.
- Enable `keepalive` to upstreams; use HTTP/2.
- Serve static assets directly from Nginx (far faster than proxying to the app).

Nginx's event-driven model handles tens of thousands of concurrent connections on modest hardware
— which is why it's the default edge proxy.
