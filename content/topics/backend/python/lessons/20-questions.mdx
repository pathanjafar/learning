# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, run, and verify.

## Practice tasks

**Easy**
1. Use list/dict comprehensions to transform data.
2. Read a CSV and summarize a column.
3. Write a function with `*args` and `**kwargs`.

**Medium**
4. Build a FastAPI service with a couple of endpoints.
5. Use a generator to stream large data lazily.
6. Write a context manager (`with` block) for a resource.
7. Add type hints and validate with `pydantic`.

## Interview questions

1. List vs tuple vs set vs dict — when each?
2. What is the GIL and how does it affect concurrency?
3. Mutable vs immutable types — implications for default arguments?
4. What are decorators and how do they work?
5. Generators vs lists — memory trade-off?
6. How do `*args` and `**kwargs` work?
7. How does Python manage memory and garbage collection?
