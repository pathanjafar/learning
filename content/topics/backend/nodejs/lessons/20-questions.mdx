# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, run, and verify.

## Practice tasks

**Easy**
1. Build an Express server with `/health` and `/echo` routes.
2. Read and write a JSON file with `fs/promises`.
3. Create a CLI that takes arguments and prints a result.

**Medium**
4. Build a REST API with CRUD endpoints (in-memory store).
5. Add middleware for logging and error handling.
6. Stream a large file to the response.
7. Connect to a database and expose a queried endpoint.

## Interview questions

1. What is the event loop and how does non-blocking I/O work?
2. How does Node handle concurrency on a single thread?
3. CommonJS vs ES modules?
4. What are streams and when do you use them?
5. How do you handle errors in async code?
6. What is middleware in Express?
7. How would you scale a Node app across CPU cores?
