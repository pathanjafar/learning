# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, run, and verify.

## Practice tasks

**Easy**
1. Model a `User` class with fields, constructor, and methods.
2. Use `ArrayList` and `HashMap` to process data.
3. Read input and process it with `Scanner`.

**Medium**
4. Define an interface and two implementing classes (polymorphism).
5. Use generics to build a type-safe container.
6. Use streams to filter and map a collection.
7. Build a small Spring Boot REST endpoint.

## Interview questions

1. What are the four pillars of OOP, with examples?
2. Interface vs abstract class?
3. `==` vs `.equals()` — and the `equals`/`hashCode` contract?
4. Checked vs unchecked exceptions?
5. How does the JVM work (bytecode, JIT)?
6. What are generics and type erasure?
7. `ArrayList` vs `LinkedList` — trade-offs?
