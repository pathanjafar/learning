# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, run, and verify.

## Practice tasks

**Easy**
1. Create a multi-page app with the App Router (home, about, dynamic route).
2. Build a Server Component that fetches and renders data.
3. Add a shared layout with navigation.

**Medium**
4. Build an API route (`app/api/.../route.ts`) and call it from the client.
5. Implement a dynamic route with `generateStaticParams`.
6. Add loading and error UI with `loading.tsx` / `error.tsx`.
7. Mix a Server Component with an interactive Client Component island.

## Interview questions

1. Server Components vs Client Components — when use each?
2. SSR vs SSG vs ISR vs client rendering — trade-offs?
3. How does file-based routing work in the App Router?
4. Why is SSR good for SEO?
5. How do you fetch data in a Server Component, and how is it cached?
6. What does `"use client"` do?
7. How do API routes fit into a Next.js app?
