# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, test in a browser, and verify.

## Practice tasks

**Easy**
1. Build a centered card with padding, rounded corners, and a shadow using utilities only.
2. Make a button with hover and focus variants.
3. Create a responsive grid (1 column on mobile, 3 on desktop).

**Medium**
4. Implement a dark-mode toggle using the `dark:` variant.
5. Build a responsive navbar that collapses on small screens.
6. Recreate a complex component (e.g. a pricing card) with utilities.
7. Extend the theme in `tailwind.config.js` with custom colors.

## Interview questions

1. What does "utility-first" mean, and what are its trade-offs vs writing CSS?
2. How do responsive prefixes (`md:`, `lg:`) work?
3. How do state variants (`hover:`, `focus:`, `dark:`) work?
4. How does Tailwind keep the production CSS bundle small?
5. When would you use `@apply` or extract a component?
6. How do you customize the design scale?
