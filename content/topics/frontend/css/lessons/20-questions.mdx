# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, test in a browser, and verify.

## Practice tasks

**Easy**
1. Center a div both horizontally and vertically (try flexbox and grid).
2. Build a responsive 3-column card layout that stacks on mobile.
3. Style a button with hover, focus, and active states.

**Medium**
4. Create a sticky header that stays on scroll.
5. Build a CSS-only dropdown menu.
6. Implement a dark-mode theme with CSS variables.
7. Recreate a pricing table with equal-height columns.

## Interview questions

1. Explain the box model and `box-sizing: border-box`.
2. How does specificity decide which rule wins?
3. Flexbox vs Grid — when do you use each?
4. What's the difference between `relative`, `absolute`, `fixed`, and `sticky` positioning?
5. How do `em`, `rem`, `%`, `vh`, and `px` differ?
6. What causes margin collapse?
7. How do media queries enable responsive design?
