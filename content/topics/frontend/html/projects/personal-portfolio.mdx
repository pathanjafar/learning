# Personal portfolio page

Build a single-page personal portfolio using **only HTML** (you'll style it in the CSS topic).
The goal is to practice semantic structure and accessibility.

## Requirements

- A `<header>` with your name and a `<nav>` linking to the sections below.
- A `<main>` containing three `<section>`s: **About**, **Projects**, **Contact**.
- The Projects section lists at least 3 items using a `<ul>`.
- The Contact section includes a `<form>` with labelled `name`, `email`, and `message` fields
  and a submit `<button>`.
- A `<footer>` with a copyright line.
- All images have `alt` text; the page has a `<title>` and `lang` attribute.

## Stretch goals

- Use an `<address>` element for contact details.
- Add an accessible skip-to-content link.

## How to check yourself

Run your HTML through an accessibility linter (e.g. the browser's Lighthouse "Accessibility"
audit) and aim for 100. Auto-grading for HTML projects is a planned platform feature.
