# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Build, test in a browser, and verify.

## Practice tasks

**Easy**
1. Build a semantic page using `header`, `nav`, `main`, `section`, `footer`.
2. Create an accessible form with labelled inputs and a submit button.
3. Make a table with a caption and proper `th` scopes.

**Medium**
4. Build a responsive image gallery using `<picture>` and `srcset`.
5. Add an accessible skip-to-content link and ARIA landmarks.
6. Create a navigation menu that's keyboard-navigable.

## Interview questions

1. What's the difference between semantic and non-semantic elements? Why prefer semantic ones?
2. Explain the difference between `id` and `class`.
3. What does the `alt` attribute do and when should it be empty?
4. Block vs inline elements — give examples.
5. How do you make a form accessible?
6. What's the purpose of the `<meta viewport>` tag?
