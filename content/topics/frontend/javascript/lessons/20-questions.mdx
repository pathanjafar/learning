# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Practice tasks

**Easy**
1. Reverse a string and check for a palindrome.
2. Use `map`, `filter`, and `reduce` to transform an array.
3. Debounce a function.

**Medium**
4. Implement a deep clone of a nested object.
5. Write a function that flattens a nested array.
6. Build a simple event emitter (on/emit/off).
7. Implement `Promise.all` from scratch.

## Interview questions

1. Explain `var` vs `let` vs `const` and hoisting.
2. What is a closure? Give a practical use.
3. How does the event loop handle async code (microtasks vs macrotasks)?
4. What is `this` and how is it determined?
5. Difference between `==` and `===`.
6. Explain prototypal inheritance.
7. What's the difference between `null` and `undefined`?
8. How do `async/await` and Promises relate?
