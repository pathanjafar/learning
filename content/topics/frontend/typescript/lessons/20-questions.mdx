# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Practice tasks

**Easy**
1. Type a function that takes a `User` interface and returns a greeting.
2. Use a union type and narrow it with a type guard.
3. Make a generic `identity<T>` function.

**Medium**
4. Model an API response with discriminated unions.
5. Write a generic `Result<T, E>` type and use it.
6. Use utility types (`Partial`, `Pick`, `Omit`, `Record`) on a model.
7. Type an async function fetching and returning typed data.

## Interview questions

1. What problems does TypeScript solve over plain JavaScript?
2. `interface` vs `type` — when do you use each?
3. What is a union vs an intersection type?
4. Explain generics with an example.
5. What are `unknown`, `any`, and `never`?
6. What is structural typing?
7. How do type guards narrow types at runtime?
