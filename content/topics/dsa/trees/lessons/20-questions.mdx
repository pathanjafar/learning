# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Coding practice

**Easy**
1. Maximum depth of a binary tree.
2. Invert a binary tree.
3. Check if two trees are identical.
4. Inorder / preorder / postorder traversal.
5. Symmetric tree check.

**Medium**
6. Level-order traversal (BFS).
7. Binary tree right-side view.
8. Path sum (does a root-to-leaf path equal a target?).
9. Lowest common ancestor of two nodes.
10. Construct a tree from preorder + inorder.
11. Diameter of a binary tree.

**Hard**
12. Serialize and deserialize a binary tree.
13. Binary tree maximum path sum.
14. Vertical order traversal.

## Interview questions

1. Compare DFS and BFS for trees — when to use each?
2. What's the difference between the three DFS orderings?
3. How does tree height affect operation complexity?
4. How would you detect whether a tree is balanced?
5. Why is recursion natural for tree problems?
