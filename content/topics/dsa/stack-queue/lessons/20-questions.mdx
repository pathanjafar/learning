# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Coding practice

**Easy**
1. Valid parentheses (matching brackets).
2. Implement a queue using two stacks.
3. Implement a stack using two queues.
4. Min stack (push/pop/top/getMin in O(1)).

**Medium**
5. Daily temperatures (next warmer day) — monotonic stack.
6. Next greater element.
7. Evaluate Reverse Polish Notation.
8. Decode string (e.g. `3[a2[c]]`).
9. Asteroid collision.

**Hard**
10. Largest rectangle in a histogram.
11. Basic calculator with parentheses.
12. Sliding window maximum (deque).

## Interview questions

1. When do you choose a stack vs a queue?
2. What is a monotonic stack and what problems does it solve?
3. Why use a `deque` instead of a list for a queue in Python?
4. How does the call stack relate to recursion?
5. Describe a real-world use of a priority queue vs a plain queue.
