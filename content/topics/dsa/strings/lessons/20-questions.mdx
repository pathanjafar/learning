# Practice & Interview Questions

> Attempt these on your own — no answers are provided here on purpose. Work them out, then verify
> against a trusted source or discuss with a peer.

## Coding practice

**Easy**
1. Reverse a string.
2. Check if a string is a valid palindrome (ignore case and non-alphanumeric characters).
3. Determine whether two strings are anagrams.
4. Find the first non-repeating character in a string.
5. Return the length of the last word in a sentence.

**Medium**
6. Longest substring without repeating characters.
7. Group a list of words into anagram groups.
8. Longest palindromic substring.
9. Implement `atoi` (string → integer) with overflow handling.
10. Longest common prefix among an array of strings.

**Hard**
11. Minimum window substring containing all characters of a target.
12. Edit distance between two strings.
13. Find all start indices of a pattern's anagrams in a text.

## Interview questions

1. Why are strings immutable in Python and Java, and what's the performance trap?
2. How does the sliding-window technique apply to substring problems?
3. Explain how KMP achieves O(n + m) pattern matching.
4. When would you count characters with a 26-element array vs a hash map?
5. How do Unicode and multibyte characters complicate string processing?
