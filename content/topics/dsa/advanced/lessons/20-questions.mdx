# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Coding practice

**Union-Find**
1. Number of connected components in an undirected graph.
2. Redundant connection (find the edge creating a cycle).
3. Accounts merge.

**Bit manipulation**
4. Single number (XOR).
5. Counting bits for 0..n.
6. Subsets via bitmask.

**Advanced graphs / trees**
7. Minimum spanning tree (Kruskal or Prim).
8. Bellman-Ford with negative edges.
9. Range sum query with updates (segment tree / Fenwick).

**Hard**
10. Travelling salesman with bitmask DP.
11. Implement KMP pattern matching.
12. Lowest common ancestor with binary lifting.

## Interview questions

1. How does Union-Find achieve near-O(1) with path compression and union by rank?
2. What problems are bit tricks (`x & (x-1)`, XOR) ideal for?
3. When do you need a segment tree instead of a prefix-sum array?
4. Compare Dijkstra, Bellman-Ford, and Floyd-Warshall.
5. What is bitmask DP and when is it feasible?
