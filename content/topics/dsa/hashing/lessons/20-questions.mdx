# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Coding practice

**Easy**
1. Two Sum (return indices of the pair summing to a target).
2. Contains Duplicate.
3. Count the frequency of each element in an array.
4. Find the intersection of two arrays.
5. Check if two strings are isomorphic.

**Medium**
6. Group anagrams.
7. Top K frequent elements.
8. Subarray sum equals K.
9. Longest consecutive sequence.
10. First missing positive (using a set).

**Hard**
11. LRU cache (hash map + doubly linked list).
12. Count distinct substrings using hashing.

## Interview questions

1. What is a hash collision and how is it resolved (chaining vs open addressing)?
2. What's the average vs worst-case complexity of hash-map operations, and why?
3. When does hashing beat sorting for a problem, and vice versa?
4. What makes a good hash function?
5. How does load factor affect performance and resizing?
