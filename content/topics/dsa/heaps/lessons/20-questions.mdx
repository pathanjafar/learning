# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Coding practice

**Easy**
1. Find the Kth largest element in an array.
2. Last stone weight.
3. Build a heap from an array.

**Medium**
4. Top K frequent elements.
5. K closest points to the origin.
6. Merge K sorted lists.
7. Task scheduler.
8. Reorganize a string so no two adjacent chars match.

**Hard**
9. Find the median from a data stream (two heaps).
10. Sliding window median.
11. IPO / maximize capital (two heaps).
12. Smallest range covering elements from K lists.

## Interview questions

1. What's the cost of push, pop, and peek on a heap?
2. How do you make a max-heap in a language that only ships a min-heap?
3. Why is a size-K heap optimal for "top K" (O(n log k))?
4. How does the two-heap pattern maintain a running median?
5. How is a binary heap stored in an array (parent/child indices)?
