Given an integer array `nums` and an integer `k`, rotate the array to the **right** by `k` steps.
Return the rotated array.

### Input format (stdin)
- Line 1: the array as JSON, e.g. `[1,2,3,4,5,6,7]`
- Line 2: the integer `k`, e.g. `3`

### Output format (stdout)
- The rotated array as JSON with a space after each comma, e.g. `[5, 6, 7, 1, 2, 3, 4]`

### Example
```
Input:
[1,2,3,4,5,6,7]
3

Output:
[5, 6, 7, 1, 2, 3, 4]
```
