Given an array of integers `nums` and an integer `target`, return the **indices** of the two
numbers that add up to `target`.

You may assume each input has **exactly one solution**, and you may not use the same element
twice. Return the indices in ascending order.

### Input format (stdin)
- Line 1: the array as JSON, e.g. `[2,7,11,15]`
- Line 2: the integer target, e.g. `9`

### Output format (stdout)
- The two indices as a JSON array with a space after the comma, e.g. `[0, 1]`

### Example
```
Input:
[2,7,11,15]
9

Output:
[0, 1]
```
Because `nums[0] + nums[1] == 2 + 7 == 9`.
