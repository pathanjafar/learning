Given an integer array `nums`, return an array `answer` where `answer[i]` is the product of all
elements of `nums` except `nums[i]`. Solve without division.

### Input format (stdin)
- Line 1: the array as JSON, e.g. `[1,2,3,4]`

### Output format (stdout)
- The answer array as JSON with a space after each comma, e.g. `[24, 12, 8, 6]`

### Example
```
Input:
[1,2,3,4]

Output:
[24, 12, 8, 6]
```
