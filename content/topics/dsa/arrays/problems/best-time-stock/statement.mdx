You are given an array `prices` where `prices[i]` is the price of a stock on day `i`. Maximize
profit by choosing a single day to buy and a later day to sell. Return the maximum profit, or
`0` if no profit is possible.

### Input format (stdin)
- Line 1: the prices array as JSON, e.g. `[7,1,5,3,6,4]`

### Output format (stdout)
- A single integer, e.g. `5`

### Example
```
Input:
[7,1,5,3,6,4]

Output:
5
```
Buy on day 1 (price 1), sell on day 4 (price 6): profit 5.
