Given an integer array `nums`, return `true` if any value appears **at least twice**, and
`false` if every element is distinct.

### Input format (stdin)
- Line 1: the array as JSON, e.g. `[1,2,3,1]`

### Output format (stdout)
- `true` or `false`

### Example
```
Input:
[1,2,3,1]

Output:
true
```
