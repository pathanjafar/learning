Given an integer array `nums`, move all `0`s to the end while keeping the relative order of the
non-zero elements. Do it in place and return the resulting array.

### Input format (stdin)
- Line 1: the array as JSON, e.g. `[0,1,0,3,12]`

### Output format (stdout)
- The resulting array as JSON with a space after each comma, e.g. `[1, 3, 12, 0, 0]`

### Example
```
Input:
[0,1,0,3,12]

Output:
[1, 3, 12, 0, 0]
```
