# Arrays cheatsheet

| Need | Technique | Cost |
|------|-----------|------|
| Find a pair summing to target | Hash map of complements | O(n) |
| Subarray with property | Sliding window / prefix sum | O(n) |
| In-place dedupe / move | Two pointers | O(n) |
| Kth largest / smallest | Heap | O(n log k) |

**Watch for:** off-by-one in bounds, empty input, duplicate values, integer overflow (Java).
