answer: |
  In-place means O(1) extra space — you reuse the input array rather than allocating a new one
  proportional to n. Use a write pointer: scan with a read index and copy/swap kept elements to
  the next write slot. Move Zeroes and Remove Duplicates are canonical examples. The trade-off is
  that you mutate the caller's data, which can be surprising; document it or copy first if the
  caller needs the original.
