  Kadane's algorithm, O(n) time / O(1) space:

  ```python
  def maxSubArray(nums):
      best = cur = nums[0]
      for n in nums[1:]:
          cur = max(n, cur + n)
          best = max(best, cur)
      return best
  ```

  Key insight: `cur` is the best subarray sum *ending at the current index* — either start fresh
  at `n` or extend the previous run. `best` records the maximum seen. Handles all-negative arrays
  because we seed with `nums[0]` rather than 0.
