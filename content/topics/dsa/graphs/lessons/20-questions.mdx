# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Work them out, then verify or discuss.

## Coding practice

**Easy**
1. Find if a path exists between two nodes.
2. Count connected components.
3. BFS and DFS traversal of a graph.

**Medium**
4. Number of islands.
5. Clone a graph.
6. Course schedule (detect a cycle / topological order).
7. Rotting oranges (multi-source BFS).
8. Pacific–Atlantic water flow.
9. Word ladder.

**Hard**
10. Dijkstra's shortest path.
11. Alien dictionary (topological sort).
12. Network delay time.
13. Word ladder II (all shortest transformation sequences).

## Interview questions

1. Adjacency list vs adjacency matrix — trade-offs?
2. When does BFS give the shortest path, and when does it not?
3. How do you detect a cycle in a directed vs undirected graph?
4. Explain topological sort and a use case.
5. When would you use Union-Find instead of DFS/BFS?
