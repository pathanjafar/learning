# Practice & Interview Questions

> Attempt these on your own — no answers are provided. Write the queries and test them.

## Practice tasks

**Easy**
1. Select all active users ordered by signup date.
2. Count rows grouped by a category column.
3. Insert, update, and delete a row.

**Medium**
4. Join users to their orders and show totals per user.
5. Find the second-highest salary.
6. Use `GROUP BY` + `HAVING` to filter aggregates.
7. Write a subquery to find users with above-average order totals.

**Hard**
8. Use a window function to rank rows within groups.
9. Find duplicate records and keep only one.
10. Write a recursive CTE to traverse a hierarchy.

## Interview questions

1. INNER vs LEFT vs RIGHT vs FULL join?
2. `WHERE` vs `HAVING`?
3. What is a primary key vs a foreign key?
4. What does an index do, and what's the downside?
5. What is normalization and why does it matter?
6. `GROUP BY` vs window functions?
7. What is a transaction and what does ACID mean?
