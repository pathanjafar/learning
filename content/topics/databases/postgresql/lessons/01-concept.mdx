# PostgreSQL

**PostgreSQL** ("Postgres") is a mature, open-source relational database known for correctness,
standards compliance, and advanced features. It speaks SQL and adds a lot on top. (This platform
stores all its data in Postgres.)

## Why Postgres over plain SQL databases

- **Rich types** — `JSONB`, arrays, `UUID`, ranges, full-text search, geometric types.
- **ACID transactions** — reliable, consistent writes.
- **Extensible** — custom functions, extensions like PostGIS.
- **Concurrency** — MVCC lets readers and writers not block each other.

## Connecting & basics

```sql
CREATE TABLE users (
  id    SERIAL PRIMARY KEY,
  name  TEXT NOT NULL,
  email TEXT UNIQUE,
  data  JSONB,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

`SERIAL` auto-increments; `JSONB` stores structured JSON you can query:
```sql
SELECT data->>'theme' FROM users WHERE id = 1;
```

## Indexes & performance

```sql
CREATE INDEX idx_users_email ON users (email);
EXPLAIN ANALYZE SELECT * FROM users WHERE email = 'ada@x.com';
```

`EXPLAIN ANALYZE` shows the query plan — essential for tuning slow queries.

## In practice

You'll usually access Postgres through an ORM (Prisma, SQLAlchemy, Hibernate) rather than raw SQL,
but understanding tables, indexes, transactions, and the query planner is what separates a working
schema from a fast one. Postgres is the default choice for most new relational backends.
